# SRF-CX-001 用語集

ScholarRepo-Finder における候補選定と検索で使用する重要用語を定義する。

## 再利用可能な提供物

### 関数提供型リポジトリ
**定義**: 他のプログラム、研究コード、または利用者が呼び出して再利用できる関数、クラス、モジュール、パッケージ、またはライブラリを主目的として提供するリポジトリ。

**判定例**:
- C/C++: 公開ヘッダと対応する実装ファイル
- Python: import可能なパッケージと公開API
- Rust: `lib.rs` と公開関数・型
- JavaScript/TypeScript: パッケージの公開export

**関連**: 実行可能なCLIやデモを持っていても、再利用可能な提供物を備える場合は関数提供型として扱う。

### モジュール型アプリケーション
**定義**: 実行入口を持つが、ドメインロジックが責務別モジュールへ分離され、そのモジュールを他用途へ転用できるリポジトリ。

**例**: `main.c` とは別に `simulation.c/.h`、`map.c/.h`、`unit.c/.h` を持つシミュレーション。

**関連**: 関数提供型より優先度は低いが、実行専用アプリケーションより優先する。

### 実行専用アプリケーション
**定義**: UI、CLI、または単一の実行フローが主目的で、再利用可能なAPIやモジュール境界を確認できないリポジトリ。

**関連**: 除外対象ではないが、関数提供型・モジュール型より低い優先度とする。

### ML（機械学習）
**定義**: データから規則を学習して予測、分類、最適化などを行う技術分野。

**使い分け**: MLであること、またはML依存ライブラリを使うこと自体は、再利用性・品質の加点根拠にしない。MLリポジトリも、他分野と同じ関数提供性の基準で評価する。
